AWS Cloud Architecture Stack

Production-grade infrastructure components powering image ingestion, storage, serverless processing, and transactional metadata:

Compute Tier

Amazon EC2

Hosts the Flask 3.x WSGI web application, serving user interfaces, RESTful diagnostics, and coordinating image ingestion workflows.

Module 1 Status: Application Ready
Storage Tier

Amazon S3

Scalable cloud object storage in ap-south-1 (Mumbai). Stores raw incoming images under uploads/ prefix with private access policies and presigned URLs.

Module 3 Status: S3 Integrated (ap-south-1)
Database Tier

Amazon RDS

Managed MySQL database storing image metadata, dimensions, processing stages, and execution audit logs with relational integrity.

Module 5 Status: RDS MySQL Integrated
Serverless Tier

AWS Lambda

Serverless event-driven compute triggered upon S3 object creation to perform non-blocking Pillow transformations, orientation correction, and 800x800 resizing.
